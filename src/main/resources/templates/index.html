 Hệ Thống 4 Nhóm Đặc Tả OpenAPI 3.1

                    
                        Tách nhóm spec theo nguyên tắc phân quyền và đối tượng client (D1, D2, D8)
                    
                


                

                    
                    

                        
                            Deprecated v1
                        
                        
1. public-v1

                        

                            Spec dành cho app khách hàng phiên bản cũ. Trả về totalAmount dạng số (được đánh dấu Deprecated).
                        

                        
                             Xem JSON Spec v1
                        
                    


                    
                    

                        
                            Recommended v2
                        
                        
2. public-v2

                        

                            Spec khách hàng chuẩn hóa mới. Trả về cấu trúc đối tượng tiền tệ đa quốc gia total: {value, currency}.
                        

                        
                             Xem JSON Spec v2
                        
                    


                    
                    

                        
                            Admin Role
                        
                        
3. admin

                        

                            Quản trị viên nội bộ TechShop. Phục vụ upload hóa đơn PDF, xem báo cáo doanh thu ngày, duyệt mọi chuyển trạng thái.
                        

                        
                             Xem JSON Admin Spec
                        
                    


                    
                    

                        
                            Partner Key
                        
                        
4. partner

                        

                            Dành cho đối tác vận chuyển. Bảo mật qua header X-Partner-Key cho endpoint webhook giao hàng.
                        

                        
                             Xem JSON Partner Spec
                        
                    

                


                
                

                    

                         Công Cụ Sinh Token Bearer JWT (HMAC-SHA256)
                    

                    

                        Sử dụng token này để dán vào nút Authorize trên Swagger UI hoặc gửi kèm trong Header Authorization: Bearer <token>.
                    

                    

                        
                        
                        
                             Đã sao chép token vào clipboard!
